## cmeAnalysis (Danuser Lab)

* **What:** the MATLAB detection code whose default
  `loadConditionData` + `runDetection` path is re-implemented here; the
  algorithms, defaults and output semantics of `pointSourceDetection`,
  `fitGaussians2D`, `getGaussianPSFsigmaFromData`, `runDetection` and their
  helpers. `reference_tools/psd_dump.m` is a modified copy of
  `pointSourceDetection.m` (debug hooks added, mixture branch removed) used
  only to generate regression data.
* **Authors / source:** Francois Aguet and the Danuser Lab,
  <https://github.com/DanuserLab/cmeAnalysis>.
* **Licence:** GNU GPL v3 (`GPL-License.txt` in the upstream repository; the
  same text as [LICENSE](LICENSE)).

## GNU Scientific Library (GSL) 2.8 — pre-built

* **What:** `third_party/gsl/` — headers, `gsl.dll`, `gslcblas.dll` and the
  import libraries `gsl.lib`, `gslcblas.lib`, built for x64 Windows / MSVC
  with vcpkg (provenance: `third_party/gsl/share/gsl/vcpkg_abi_info.txt`).
  Used for distributions, vectors/matrices, BLAS and linear algebra. The
  debug-symbol (`.pdb`) files of the original build are not included.
* **Source:** <https://www.gnu.org/software/gsl/>.
* **Licence:** GNU GPL v3 — `third_party/gsl/COPYING`.

## GNU Scientific Library 1.16 — Levenberg–Marquardt sources

* **What:** `third_party/gsl116/` — the unmodified GSL 1.16
  `multifit/lmder.c`, `lmutil.c`, `lmpar.c`, `lmset.c`, `lmiterate.c`,
  `qrsolv.c`, `covar.c`, `convergence.c` (Copyright (C) 1996–2007 Brian
  Gough) and the QR routines from `linalg/qr.c` (Copyright (C) 1996–2007
  Gerard Jungman, Brian Gough), compiled against GSL 2.8 through the small
  wrappers `g116_lm.c` / `g116_linalg.c`. The 1.16 solver is used because
  it is the one the original cmeAnalysis `fitGaussian2D` MEX was built
  with (see `PORTING_NOTES.md` §2.4). `g116_blas.h` re-implements the few
  level-1 BLAS routines the solver calls (`ddot`, `daxpy`, `dscal`, `dnrm2`,
  `idamax`) and some vector copy/permute helpers, following the reference
  gslcblas / GSL vector sources operation for operation (GPL-3.0), so that the
  solver does not cross the DLL boundary in its inner loops.
* **Licence:** GNU GPL v3 — `third_party/gsl116/COPYING`.

## MATLAB / MathWorks

No MATLAB toolbox source code is included. MATLAB and toolbox `.m` files
were only read to determine the exact semantics that the port must
reproduce (documented in `PORTING_NOTES.md`). The reference values in
`tests/reference_values.txt` and `tests/ad_reference*.txt` are numerical
outputs generated by running MATLAB R2025a and the cmeAnalysis MEX on
synthetic inputs (`reference_tools/gen_*_reference.m`).
